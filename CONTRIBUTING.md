# Contribuciones

Detector de Estafas es un producto propietario de código visible. Las contribuciones externas no se aceptan automáticamente.

## Issues

Podés abrir un issue para:

- informar un error reproducible sin datos sensibles;
- proponer una mejora concreta;
- señalar documentación incorrecta;
- informar incompatibilidades de instalación.

No uses issues públicos para vulnerabilidades. Leé `SECURITY.md`.

## Pull requests

Antes de preparar un pull request, solicitá autorización. La aceptación de código requiere un acuerdo escrito que defina derechos de uso, autoría y licencia.

Un pull request no implica que el titular acepte, integre o publique la contribución.

## Reglas mínimas

- No incluir secretos ni datos reales.
- No agregar dependencias sin justificar licencia, seguridad y costo.
- Mantener pruebas sin dependencia directa de Internet.
- No almacenar contenido analizado por defecto.
- Respetar el motor local como resultado determinista principal.
- No afirmar precisión, identidad telefónica ni fraude sin evidencia.
