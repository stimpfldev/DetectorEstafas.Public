BLOQUE 2H.1 - BASE DE API COMERCIAL VERSIONADA

1. Copiar el contenido sobre la raíz de DetectorEstafas.
2. Reemplazar Program.cs y DetectorEstafas.Web.csproj.
3. No ejecutar migraciones.
4. Configurar la API key mediante User Secrets:

   dotnet user-secrets set "ApiComercial:Enabled" "true" --project DetectorEstafas.Web
   dotnet user-secrets set "ApiComercial:Keys:0:Name" "cliente-prueba" --project DetectorEstafas.Web
   dotnet user-secrets set "ApiComercial:Keys:0:Key" "UNA-CLAVE-LARGA-ALEATORIA" --project DetectorEstafas.Web
   dotnet user-secrets set "ApiComercial:Keys:0:Enabled" "true" --project DetectorEstafas.Web

5. Compilar y ejecutar.
6. OpenAPI: /openapi/v1.json
7. Endpoint: POST /api/v1/analisis
8. Header obligatorio: X-Api-Key

Ejemplo JSON:
{
  "tipoContenido": 1,
  "contenido": "Último aviso. Enviá tu código de seguridad."
}

No se almacena el contenido enviado. Solo se registra la métrica anónima existente con origen API.
